# Crypto Market Evolution App

A simple web app for visualizing crypto price curves, market volume, and chart variations using CoinGecko data.

## Features

- **Multi-crypto comparison**: Select multiple cryptocurrencies to compare side-by-side on one graph
- Choose from Bitcoin, Ethereum, Cardano, Binance Coin, and Solana
- **Time ranges**: Select 7, 14, 30, 90 day or 1 year history
- **All-time historical data**: View data from each coin's inception (Bitcoin since 2009, Ethereum since 2015, etc.)
- Switch graph views: line, bar, area, and mixed
- Loads in any modern web browser
- short story of each crypto selected in this app in a second page
- switch from dark to light-mode

## Run locally

1. Open `index.html` in your browser.
2. Or use a simple web server such as VS Code Live Server.

## Notes

- The app requires internet access to fetch market data from CoinGecko.
- If the API is unavailable, the app displays fallback sample chart data.
